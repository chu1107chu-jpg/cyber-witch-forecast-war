## Честные метрики (с объяснением)

| Метрика | target_p5_up | target_p20_up |
|---|---|---|
| Точность числом | 56.6% | 58.9% |
| Dummy baseline (всегда UP) | 54.0% | 60.3% |
| Реальный отрыв от baseline | **+2.6%** | **−1.4%** |
| ROC-AUC OOS | 0.496 | 0.494 |
| Вывод | Минимальный сигнал | Хуже случайного |

### Почему 56% не равно "мы умнее рынка"

2024–2026 — бычий рынок. Большинство дней акции росли.
Модель, которая **всегда говорит UP**, даёт 60% точность на 20 днях.
Наша модель — 58.9%. То есть мы хуже простого buy-and-hold.

**ROC-AUC = 0.495** — реальная мера. Это случайное угадывание.

## Почему не получается 53%+ стабильно

Технические индикаторы (RSI, MACD, скользящие) — публично известны.
Рынок их уже учёл. Чтобы выйти за 53%, нужны:
1. Альтернативные данные (новостной сентимент NLP, позиции СОТ)
2. Макрорежим (VIX, кривая доходности, DXY)
3. Корреляционные сигналы между инструментами
4. Более длинный горизонт (месяц+) — на нём закономерностей больше

---

## Будет ли модель переобучаться сама по себе?

**Нет.** Это статический pickle-файл. Сам по себе не меняется.

Но рыночный режим меняется, и через 6–12 мес текущая модель может
давать хуже. Нужен плановый перезапуск `scripts/train_lgbm.py`.

---

## Можно ли вообще получить 53%+?

Да, на горизонте 20+ дней с правильными фичами.
**Академические данные:** обычные технические индикаторы → ~51-52%.
С добавлением VIX + сентимент + Cross-sectional momentum → 53-55%.
