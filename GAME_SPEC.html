1. Общее описание

Political Arena — браузерная файтинг-игра в стиле horror, где политики дерутся друг с другом. 44 бойца со статами, именными ударами-мемами и уникальными спецприёмами.

Стек

КомпонентТехнология
BackendPython 3.11+, FastAPI, uvicorn (порт 8502)
FrontendVanilla JS + CSS (без фреймворков)
БДSQLite → PostgreSQL при масштабировании
ДеплойMAMP (Apache) на Mac → VPS / Railway / Fly.io

Визуальный стиль

Тёмный horror — чёрные/бордовые тона, неоновые акценты оранжевого и золота, грубая игровая стилистика.

2.1 Заставка (Splash Screen)

  • Полноэкранная картинка-заставка (будет предоставлена позже)
  • Прогресс-бар загрузки ассетов (аватары, звуки)

  • Фоновая horror-музыка начинает играть

2.2 Главная / Лобби

  • Логотип + название
  • Кнопки: "ИГРАТЬ", "Таблица рекордов", "Настройки"
  • Авторизация: вход по email / телефон / Google
  • Баланс ₲ (токены) в правом верхнем углу

2.3 Ростер (выбор бойцов)

  • Сетка крупных карточек бойцов (подробности в разделе 4)
  • Переключатель режима: vs AI / vs Игрок (hot-seat)
  • 2 слота: ИГРОК 1 / ИГРОК 2 (или AI)
  • Кнопка "В БОЙ!" (активна когда оба слота заполнены)
  • Ставка на бойца + сумма ₲
  • ★ Избранные бойцы (хранятся в БД, отмечаются после боя)

  • 3 раунда, 45 секунд на раунд
  • HUD сверху: аватары, имена, HP-бары, combo-бар, раунд, таймер
  • Центр: анимированный бой (CSS-анимации + фото бойцов)

  • При vs AI — кнопки второго игрока скрыты
  • Мобильные тач-кнопки (яркие, полупрозрачные)
  • Лог ударов внизу

2.5 Результат

  • Портрет победителя + его фраза (taunt)

5. Боевая механика

5.1 Типы атак

ТипКлавиша (P1)МножительОписание
Удар рукойA / D×1.0Быстрый, точный
Удар ногойW×1.7Мощный, медленнее
БлокS—Поглощает удар (600мс)
СуперударF / Space×2.5+Именной удар, нужно комбо

5.2 Формула урона

base_dmg = move.base_dmg + atk × 0.5 − enemy.def × 0.35
dmg = base_dmg × множитель × rand(0.85, 1.15)

if crit (12% + luck × 1.5%):  dmg ×= 1.6
if combo × 2:                  dmg ×= 1.3
if combo × 3:                  dmg ×= 1.6
if counter (light>special>heavy>light): dmg ×= 1.3

5.3 Суперудары (Fatality-стиль)

  • Активируются ТОЛЬКО при combo × 3 (3 успешных удара подряд)
  • Каждый боец имеет именной суперудар (поле ultimate из moves)
  • При активации:
    • Крупный текстовый оверлей с названием удара ("COVFEFE!", "Мочить в сортире!")
    • Вспышка + анимация экрана (shake + flash)
    • Усиленный звуковой эффект

Примеры суперударов

БоецСуперударУронТочность
🍊 ТрумпУкрасть президента5565%
🐻 ПутенОпоздание на 4 часа5860%
😴 Байдон(из fighters.py)——

5.4 Secret Combo (Mortal Kombat стиль)

  • У каждого бойца — скрытая комбинация клавиш для мгновенного суперудара
  • Комбинация НЕ отображается в игре (отдельный сайт-справочник позже)
  • Примеры: ↓→↓→F, ←→←→F, ↑↓↑↓F
  • При правильном вводе — мгновенный суперудар без combo × 3

5.5 Раунды

  • 3 раунда максимум
  • 45 секунд на раунд
  • Таймер вышел → побеждает боец с бо́льшим HP
  • House edge: 70% побеждает объективно сильнейший, 30% — андердог

5.6 Counter System

light > special > heavy > light (камень-ножницы-бумага)
Контр-удар даёт ×1.3 бонус к урону.
